# KDE Partition Manager

[← back](../index.md)

[KDE Partition Manager](https://apps.kde.org/partitionmanager/) is a graphical utility for managing disks, partitions and file systems. It supports creating, deleting, copying, moving and resizing partitions.

## Install KDE Partition Manager

On openSUSE:

```bash
sudo zypper install partitionmanager
```
