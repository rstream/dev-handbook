# Webstorm: Codex setup

[← back](index.md)

Codex works via JetBrains AI Assistant plugin.  Sometimes you may come across a problem: JetBrains AI free plan credits are over and Codex no longer works. This is because you are using Codex via JetBrains proxy.

## First Codex setup

After login to JetBrains AI Assistant, choose "Free Plan" and log in to Codex via ChatGPT account (not JetBrains account).

## If already in trouble

Log out from JetBrains AI Assistant and log in again. Again, log in to Codex via ChatGPT account.
